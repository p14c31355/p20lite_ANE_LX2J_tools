## 読む順番の推奨

1. **BLU (解除) を知りたい** → `../ANE_LX2J_BOOTLOADER_UNLOCK_20261002.ja.md`
   (要約) → `ANE_UNLOCK_NOTES.md` (全詳細)
2. **Fullerene の移植経過** → `../ANE_BOOT_CONTRACT.md` (契約) → `V21_STATE.md`
   (過程) → `NIGHT_v331_STATUS.md` (最新)
3. **ある日の実測を引く** → 上表の時期から該当ファイルへ

## この台帳を読む上での注意

- 当時の結論が後に撤回されている箇所がある (例: pstore 読み出しの可否は
  BOOT_CONTRACT §9 で一度肯定し同日昼に撤回)。撤回の記録も残してあるので、
  「1 行だけ読んで結論とする」のは危険。BOOT_CONTRACT が現行の正。
- 台帳内のパスは当時の作業ツリー (`~/dev/p20-root`) を指すものが多い。
  p20-root は現役の作業ディレクトリとして残っている。整備済みの同種ツールは
  本リポジトリ `tools/` にある。
