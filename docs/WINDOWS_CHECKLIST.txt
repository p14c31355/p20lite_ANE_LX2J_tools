    このファイル

■ なぜ Windows か
    HiSuite は端末を USB で認識するのに Windows カーネルドライバを使う。
    Wine では読み込めない (WineHQ bug #51666 が未解決、XDA でも実測報告あり)。
    USB パススルー付き VM でも可。デュアルブートの Windows が最も確実。


────────────────────────────────────────────────────────────────
手順 1  インストール
────────────────────────────────────────────────────────────────
    HiSuite_Setup_Windows.exe を実行。
    「HiSuite Proxy」は今は使わない (手順 5 で必要になったら)。

    ヒント: 端末自体が古い HiSuite インストーラを同梱している
            (エクスプローラに HiSuite という CD ドライブが見える)。
            新しい方が繋がらない場合の退避手段になる。


────────────────────────────────────────────────────────────────
手順 2  端末を HiSuite モードにする
────────────────────────────────────────────────────────────────
    ダイヤルパッド → *#*#2846579#*#*
      → Background Settings
      → USB Port Settings
      → 一番下の「HiSuite Mode」を選ぶ
    いったんケーブルを抜いて差し直す。

    設定 → 検索で「HDB」→「Allow HiSuite to use HDB」を ON
      (「このコンピュータからの接続を常に許可」を選ぶ)


────────────────────────────────────────────────────────────────
手順 3  認識確認
────────────────────────────────────────────────────────────────
    HiSuite を起動。端末名と機種 (ANE-LX2J) が出れば成功。
    エクスプローラに「HiSuite CD Drive」が見えるのも認識の目印。

    繋がらない場合:
      - ケーブルを別の USB ポートへ
      - 端末側の USB モードを「File transfer」に変えて再度 HiSuite Mode へ
      - HiSuite のバージョンを変える


────────────────────────────────────────────────────────────────
手順 4  ロールバックの有無を確認する  ← 本題
────────────────────────────────────────────────────────────────
    HiSuite の「Update」をクリック。
    画面右下に「switch to an older version（以前のバージョンに切り替え）」
    が出るかどうかを見る。

    【出た場合 → 成功ルート】
      そのまま実行。HiSuite が EMUI 8 へロールバックする。
      データは消える。初期設定画面になれば EMUI 8 の証拠。
      → 手順 6 へ。

    【出ない場合 → 手順 5 へ】

    参考: このボタンは「EMUI 9 の初期ビルド」でのみ出るという報告がある。
          当方の端末は 9.1.0.132 = 9.1 の初期ビルドなので条件は満たす見込み。
          HUAWEI 公式も「ロールバック可能な時だけ表示される」と説明している。


────────────────────────────────────────────────────────────────
手順 5  出なかった場合: HiSuite Proxy
────────────────────────────────────────────────────────────────
    HiSuite.Proxy.V3.3.0.zip を展開して実行。
      - httpcomponent.dll を選んでパッチ (HiSuite 側)
      - プロキシを 127.0.0.1:7777 に設定
      - 端末の CUST / PRELOAD を確認する
          *#*#2846579#*#* → Version Information
          当方: CUST = C635、BASE = ANE-LGRP2-OVS 9.1.0.132

    ロールバック ROM が必要。探し方:
      https://professorjtj.github.io/BaseArchive
      https://professorjtj.github.io/  (Firm Finder)

    注意 (公式ガイドの警告):
      - CUST / PRELOAD は端末の表示と一致させること
      - ダウングレードは「1つずつ」 (9.1.0.132 → その1つ前 → …)
      - 不一致だと「Software Install Failed」で失敗する
        (当方が SD カードで見たのはまさにこの症状)


────────────────────────────────────────────────────────────────
手順 6  EMUI 8 まで落ちたら Linux に戻って確認
────────────────────────────────────────────────────────────────
    adb shell cat /proc/version
      → 4.4.23 なら成功 (7.0/8.0 系カーネル)

    adb shell getprop ro.build.display.id
      → 8.0.0.x(C635) になっていれば成功

    ※ ここまで来れば、あとは配置済みの手順だけで進める:
       /data/local/tmp/cve-2019-2215   (4.4.23 用エクスプロイト)
       実行 → root シェル

最後に
────────────────────────────────────────────────────────────────
    dload (SD カード) だけで EMUI 9 → 8 を越えることはできない。
    これは 7通りの実測と経験者の証言の両方で確定済み。
    不足していたのは HiSuite のこの 1 工程だけ。
    そして HiSuite は無料。
