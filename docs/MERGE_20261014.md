# Merge record - ~/dev consolidation 2026-10-14

`~/dev` was consolidated into this repository. This file records what was
merged, what was deliberately left in place, and what was deleted.

## Merged into this repo (copy-only, newest-wins)

From `~/dev/p20-root` (the live working tree):

- `tools/` - all 544 top-level `.sh` / `.S` / `.py` experiment scripts, plus
  the 60 `tools/` helpers (merged into `tools/verify/`).
- `docs/` - `ANE_BOOT_CONTRACT.md`, `ANE_NIGHT_20261002.md`,
  `ANE_USB_BRINGUP.md`, `V21_STATE.md` (all newer than the previous copies).
- `docs/state/` - top-level status files (`MORNING_REPORT.md`,
  `NIGHT_2026-10-06.md`, `NIGHT_v331_STATUS.md`, `STEP13_EXPECTED.md`,
  `sweep_results.txt`, `night_queue.txt`, `next_experiment.txt`,
  `mmu_off_entry_patch.txt`).
- `artifacts/` - all boot images (441 new/updated; every `-stock` variant
  stays local per `.gitignore`, only the log-probe reader is tracked).
- `firmware/ane_pstore_readback/` - pstore console/pmsg readback.
- `logs/` - `usb_runs/`, `forensics/` (snap readback), `misc/` (catch_lk and
  dump logs), `night/` (rings_night journals), `camshots/`.
- `unlock/lk_asm/` - the fuller LK disassembly set (gitignored, 12 MB).
- `unlock/working-notes/` - the winning-configuration notes.
- `refs/` - hisifb display-stack reference sources + HwProjectMenu.apk.

From `~/dev` loose files:

- `usbtool-*.py` (9 scripts) + `pz_poc.c` -> `tools/usbtool/` and
  `unlock/pz_poc.c` (PoC kept for provenance).
- `tools/apktool.jar` -> `tools/apktool/`.

## Deliberately NOT merged (still live in `~/dev`)

- `p20-root/` itself stays: it is the active working tree with the large
  binaries this repo ignores (13 GB firmware archives, kernels, sd dumps,
  hisuite, boot images, the embedded hi6250 kernel source checkout, shots/).
  Deleting it would destroy the only local copy of files this repo
  deliberately keeps out of git.
- `teclast-p20hd/` (Teclast project, active).
- `sprd-sharkl3-src/` (Unisoc kernel source checkout, active).
- `usbtool-env/` (python venv used by `tools/usbtool/*.py`).
